# 像人一样玩梗 · astrbot_plugin_meme_like_human

让机器人**真正听懂**中文网络梗和群内黑话，而不是硬猜。

内置 **10,808 条**中文网络梗词库，本地毫秒级查询，零网络依赖。

---

## 它解决什么问题

模型不认识新梗时会瞎猜。你发「蚌埠住了」，它可能一本正经地解释安徽蚌埠的地理位置。

这个插件在模型请求前，**自动把消息里命中的梗的释义注入进去**，模型就知道该笑了。

同时，每个群都会长出自己的黑话（只有本群懂的说法）。插件会从聊天记录自动学习，
判断哪些词是「本群特有」，下次出现时按需要注入。

---

## 两条能力线

### A. 全网梗

| 环节 | 说明 |
|---|---|
| **词库** | 内置 10,808 条，打包为 gz（0.92MB），首次加载建 SQLite 索引 |
| **匹配** | 首字索引 + 最长优先，单条消息 <1ms |
| **注入** | 聊天中自动识别，注入不超过 120 字的极简释义 |
| **查询** | `/玩梗 <词>` 返回完整释义 |
| **兜底** | 本地没有、且用户是在问梗时，走 DeepSeek 搜索（约 0.4s）并写回本地 |

### B. 群内黑话

| 环节 | 说明 |
|---|---|
| **收集** | 被动缓冲群消息，攒够 40 条触发一次提取 |
| **提取** | LLM 从聊天记录里挑出「可能是黑话」的候选词 |
| **判定** | **双路对照**：带上下文推断 vs 裸词推断，含义不一致才是黑话 |
| **过滤** | 单字、人名、常见词、黑名单群全部排除 |
| **注入** | 高频词标注「可以偶尔用」，低频词只让「理解」 |

## 指令

| 指令 | 说明 | 权限 |
|---|---|---|
| `/玩梗 <词>` | 查询梗的完整释义 | 所有人 |
| `/玩梗库` | 查看词库统计与署名 | 所有人 |
| `/黑话库` | 查看已学会的黑话（可翻页） | 所有人 |
| `/黑话库 stat` | 学习统计 | 所有人 |
| `/黑话库 add <词> <含义>` | 手动录入（AI 永不覆盖） | 管理员 |
| `/黑话库 del <词>` | 删除词条 | 管理员 |
| `/黑话库 global <词>` | 切换全局/仅本群 | 管理员 |

> 注意：`/梗`、`/黑话` 已被 **memewiki** 插件占用，本插件刻意避开，两者可共存。

## 安装

1. 把本仓库放进 AstrBot 的 `data/plugins/` 目录
2. 重启 AstrBot
3. 在 WebUI 的「插件管理」里确认已启用

词库已打包，**不需要任何额外下载**，装好即用。

### 可选：配置 DeepSeek Key

只有「本地词库查不到 + 用户在问梗」时才会用到搜索。

- 在插件配置里填 `deepseek_api_key`，或
- 留空让插件自动从 AstrBot 的 provider 配置里探测

都拿不到时，插件会**静默禁用兜底搜索**，本地功能完全不受影响。

## 主要配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `meme_enabled` | true | 全网梗总开关 |
| `inject_enabled` | true | 聊天中自动注入梗释义（核心功能） |
| `inject_max_memes` | 2 | 单次最多注入几个梗 |
| `search_enabled` | true | 兜底搜索开关 |
| `search_daily_max` | 200 | 全局每日搜索上限 |
| `jargon_enabled` | true | 群内黑话总开关 |
| `learn_frequency` | 40 | 攒多少条消息触发一次学习 |
| `learn_daily_max` | 30 | 每群每日提取上限 |
| `infer_daily_max` | 20 | 每群每日推断上限 |
| `provider_id` | "" | 黑话分析专用模型（建议填便宜的小模型） |
| `listen_private` | false | 是否也学私聊 |
| `blacklist_groups` | "" | 群黑名单，逗号分隔 |

## 成本

| 场景 | 开销 |
|---|---|
| 本地查梗 / 注入 | **¥0**（纯本地） |
| 兜底搜索 | 约 ¥0.0003/次，默认每天上限 200 次 |
| 黑话提取 | 每群每 40 条消息 1 次 LLM 调用 |
| 黑话推断 | 每个候选 3 次 LLM 调用，仅阈值 4/8/25/100 触发 |

限流是内置的：`search_daily_max`、`learn_daily_max`、`infer_daily_max` 三重保护。

## 双路对照是怎么判定的

这是本插件最核心的设计（思路参考 [MaiBot](https://github.com/Mai-with-u/MaiBot)，独立实现）：

```
                    词条 count 达到 4 / 8 / 25 / 100
                              ↓
            ① 带上下文推断含义 ──→ 若答 no_info，放弃本次，等下次阈值
                              ↓
                   ② 只给裸词推断含义
                              ↓
                    ③ 比较两个结果
                              ↓
        相似 ──→ 含义明确，是通用网络词，不是黑话
      不相似 ──→ 含义依赖圈内语境，是本群黑话
```

本质是：**用「含义是否依赖上下文」来定义黑话**。

细节实现：
- `count >= 100` 标记完成，不再推断
- `last_inference_count` 防止同一阈值重复推断
- 手动录入的词条 AI 永不覆盖
- 单字、人名、常见词全部过滤

## 隐私

- **聊天记录会上传给 LLM 分析**（黑话学习需要），但只上传必要的短片段
- 不收集 QQ 号、不落库昵称（昵称只用于过滤，存在内存里）
- `blacklist_groups` 可逐个群屏蔽
- `jargon_enabled: false` 可完全关闭学习
- 默认不学私聊、不学自己发的消息

## 与 memewiki 的区别

| | memewiki | 本插件 |
|---|---|---|
| 命令 | `/梗` `/黑话` | `/玩梗` `/黑话库`（不冲突）|
| 定位 | 主动查词 | **被动理解**（聊天中自动注入）|
| 词库 | 6668 条 | **10,808 条** |
| 黑话 | 无学习 | **自动学习** |
| 网络依赖 | 依赖 cnmeme.wiki（已不稳定）| **完全本地**，搜索仅兜底 |

两者可以同时安装，互不干扰。
